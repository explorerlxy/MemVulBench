## 2. 类型是不是另一次审核？

不是。五元组第一项就是类型：`heap-buffer-overflow`、`heap-use-after-free`、`null-deref` 等。ASan 直接给出的 kind 进入 `CLEAR_KINDS`；不能直接给出的由操作员裁决（ghostpdl / upx / libavc 三条）。这已经是身份的一部分。目录 CWE 粗类（A/B/C/X）只是来源标签对照，不再挡住准入。

## 3. librawspeed

expected 五元组为7，落在门规 6–7 档。操作员明确复核后准入，已核验数为7。

## 4. 仍保留的研究限制

- 已核验数量是真实总量下界；未知漏洞可能存在。
- 数量对有效评估粒度和评估效能只作定性解释。
- 不以20项目或≥8阈值声称统计代表性。
- 第3.4节相关资源的同口径系统核验未完成。
